# 世界設計ノート — 「地形が違うだけで、世界が変わる」

この文書は TERRA CRAFT の世界観・シナリオ設計の指針です。
実装の詳細は `docs/implementation-plan.md`、数値の出典は `data/` の各 JSON と `docs/data-catalog.md` を参照してください。

## 設計思想

TERRA CRAFT が表現したいのは、**地形の違いがすべての連鎖を生む**という地球システムの姿です。
山を1本描くだけで、次のような因果の連鎖が世界を貫きます:

1. **地形 → 気候**: 山脈の風上側に地形性降雨、風下側に雨陰（Roe 2005）
2. **気候 → 生態系**: 降水量が Whittaker 図上のバイオームを決め、植生が広がる
3. **地形 → 水**: 標高の高低が Priority-Flood で流向を決め、川・湖ができる
4. **水 + 生態系 → 文明**: 集落は川沿いの平地に発生し、農地が広がる
5. **文明 → 地形**: 伐採と農地が侵食を増やし、土砂が下流に堆積して地形を変える
6. **文明同士 → 経済と戦争**: 貿易は重力モデルで結ばれ、資源を巡って戦争が起きる

この連鎖が実感できることが、この作品の「面白さ」の核です。

## ショーケース世界（プリセット）

`data/terrain.json` の `presets` に、3つのショーケース世界を用意します。
いずれも固定シードで決定的に再現できます。

### 島（Island）
- **地形**: 中央に山、周囲に海岸平野
- **水**: 山から放射状に川が流れ、海岸へ注ぐ
- **生態系**: 山頂はアルパイン、中腹は森林、海岸は草原・農地
- **文明**: 湾に面した平野に港町が発達。水源を巡る国が生まれやすい

### 山脈（Mountain Range）
- **地形**: 西から東に連なる山脈と、前後の丘陵
- **水**: 山脈が分水嶺になり、南北に川が分かれる
- **生態系**: 風上側は湿潤林、風下側は雨陰の草原・砂漠——**同じ緯度なのに植生が違う**
- **文明**: 峡谷が交通の要衝になり、関所・城砦の観念が生まれる。国境は尾根に引かれやすい

### 盆地（Basin）
- **地形**: 周囲が山に囲まれた窪地
- **水**: 出口のない窪地に湖（内陸湖）ができる。乾燥気候なら塩湖
- **生態系**: 湖畔は肥沃な農地、周囲の山は乾燥林
- **文明**: オアシス文明型。水源の集中が集権国家を生みやすい

## 「地形が違うだけで世界が変わる」を体感できる演出

実装時に以下のシナリオを検証・収録します（計画書§15.3）:

| シナリオ | 何が体感できるか |
| --- | --- |
| 山を作ると川が流れる | 標高が水系を決める |
| 盆地を作ると湖ができる | 窪地に水が溜まる |
| 森を切ると侵食が増える | 植生が地形を守る |
| 乾燥させると砂漠化する | 水が生態系の上限を決める |
| 山を削ると流路が変わる | 地形の改変が水系を変える |
| ダムを作ると湖ができる | 人為的な干渉が自然を変える |

## 経済と戦争の位置づけ

経済と戦争は「自然の上に載る人間のレイヤー」です:

- **経済**: 食料・木材・鉱物の生産は地形と植生から決まり（肥沃な草原=農業、森林=木材、山岳=鉱山）、貿易は重力モデル（経済規模×距離減衰）で結ばれる。**海に面した国は交易で栄え、内陸国は輸送コストに苦しむ**——これも地形の帰結
- **戦争**: 開戦は国家の AI 性格と国力差から確率的に起きる。戦闘は Lanchester の2乗法則と地形防御（山岳2.2倍・森林1.4倍・都市2.5倍）で解決する。**山岳国は攻めにくく、平野国は攻められやすい**——地形が戦略を決める
