# 等高線を描くときのガイド

手描きの等高線は地形生成の出発点（境界条件）になる。実地形の等高線と同じ性質を
守らないと、ラスタライズした瞬間に矛盾した標高が同じセルへ書き込まれ、緩和で
意図しない地形になる。この文書は「自分で等高線を描くとき」の作法と確認手順。

## 基本原則

実地形の等高線が必ず満たす性質。terrain.json の contourRules と
scripts/validate.py が機械的に検査する内容と一致している。

1. **等高線は交差しない** — 同じ地点に2つの標高は存在しない
2. **等高線は重ならない・頂点を共有しない** — 距離0で「交差」と同じ故障になる
3. **標高は一方向に単調** — 外側から尾根や中心に向かって、標高は上がるか下がるかの
   どちらかに並ぶ（途中で上下に揺れ戻さない）
4. **閉ループの入れ子は山か盆地** — 内側ほど高い（山）か内側ほど低い（盆地）の
   どちらか。同じ標高の入れ子は中間の等高線が消えるので禁止。
   両方が混ざるのはカルデラ型として警告のみ
5. **閉ループは必ず閉じる** — 最初と最後の頂点を同じ座標にする
6. **頂点は [0,1] 内・間隔は十分に** — 頂点座標は正規化座標、隣接頂点の間隔は
   0.02 以上

## 描く手順

1. **外側から描く**。一番外側（一番低い）の等高線から順に、内側へ標高を上げていく。
   逆順で描くと「残りスペースに無理やり押し込む」ことになり交差しやすい
2. **並べて描く**。隣の等高線と同じリズムで頂点を置く（尾根に沿って「平行」に
   流す）。1本だけ急に蛇行させると交差の元
3. **距離を測る**。隣接する等高線との最短距離が基準以上あるか、ときどき確認する

## 数値の目安

正規化座標（世界の幅=1）で考える。グリッドは scale.json の `grid.sizes` を参照。

| 項目 | 基準値 | 128²グリッドでの意味 |
| --- | --- | --- |
| 等高線どうしの最小距離 | 0.04 | 約5セル以上離す |
| 隣接頂点の間隔 | 0.02 | 約2.5セル以上 |
| 頂点座標の範囲 | [0, 1] | 世界の外に描かない |

ブラシ幅の換算: 幅 `w` の等高線は `w` セルぶん太く描かれる。2本の等高線は
`(w1 + w2) / 2` セル以上離さないと同じセルに両方の標高が書き込まれ、
`overlap: average` で中間の標高に潰れる。距離の基準 0.04 は幅3と幅2の組み合わせを
128² で換算した値に余白を足したもの。

セル数 → 正規化距離の換算: `距離 = セル数 / グリッドサイズ`
（例: 128² で5セル = 5/128 ≈ 0.039）

## よくある失敗と直し方

### 交差している

```json
{"points": [[0.1,0.1],[0.9,0.9],[0.9,0.5],[0.5,0.5]], "elevation": 0.1},
{"points": [[0.1,0.9],[0.9,0.1]], "elevation": 0.5}
```

→ 1本目の「引き返し」をなくし、両方を斜めに平行に流す:

```json
{"points": [[0.1,0.1],[0.9,0.5]], "elevation": 0.1},
{"points": [[0.1,0.9],[0.9,0.1]], "elevation": 0.5}
```

### 重なっている（同じ頂点を共有）

2本の等高線で同じ座標（またはほぼ同じ座標）を使うと、どちらもそのセルに
書き込まれて平均化される。それぞれの頂点を独立に置く。

### 閉ループの標高が等しい入れ子

外側0.5の中に内側0.5を置くと、間の地形が定義されない。内側は必ず標高を変える
（山なら上げる、盆地なら下げる）。

## 描いたあとの確認

```bash
# 1本ずつ詳しく見る（ペアごとの距離・入れ子・交差を報告）
python3 scripts/check-contours.py                    # 全プリセット
python3 scripts/check-contours.py --preset mountainRange

# 単体ファイルも直接チェックできる（terrain.json に載せる前の試し描き）
python3 scripts/check-contours.py my-terrain.json

# データ全体の検証（コミット前に必須）
python3 scripts/validate.py
```

`check-contours.py` は基準に満たない項目を「どの等高線のどの頂点・どのペアか」
まで表示する。0件になったらコミットしてよい。
