# M6・M7 受け入れ記録（貿易の完成・戦争の完成）

## 範囲の整理
計画書 §22.10 の M6（貿易 5f・5g）と M7（戦争 5h〜5k）の中身の大半は M4 で実装済み。M6/M7 では残りを埋めた。

- M6: 禁輸（信頼 −10、解除しても戻らない）、食料輸入依存（DI の災害耐性に係数 `importDependencyPenalty` で反映）、上流取水→下流の信頼低下（tests で強制検証）、観測量。
- M7: ダム破壊（戦争中のみ。標高を元に戻し、次の tick に洪水。富を `sabotageCost` 消費）、守り側の反攻、AI だけのバランス統計（`src/core/balance.ts`）、公平性・決定論テスト、UI（禁輸・ダム決壊ボタン）。

## 修正した不具合
