# M5 受け入れ手順（体験の層: 観測量・シナリオ比較・因果トレーサ）

## 実装範囲
- **観測量の時系列**（`src/core/observe.ts`）: `runtime.observe.everyTicks`（4）ごとに記録、上限 `maxSamples`（300）。指標は `data/observables.json` に定義済みのものだけ（人口・降水・農地・発展度・食料安全保障・飢饉・貿易額・軍事力・国庫・技術・森林率）。世界は `id`、国は `id:国ID`。Undo で巻き戻り、同じ seed で完全に一致。UI: 指標を選んで国ごとの折れ線（色に加え線種と凡例の最新値で区別）。
- **シナリオ比較**（`src/core/compare.ts`、Worker の `compare` メッセージ）: 同じ seed で 2 つの世界（地形プリセットまたは初期の操作が違う）を別の World で同じ年数進め、指標の最終値の A/B・差 Δ・比、推移グラフ、「いちばん差が大きいのは…」の 1 行を返す。動いている世界は変わらない。進行は progress で表示。
- **因果トレーサ**: op イベントに通し番号 `opId` を付け、結果イベントの `causeId` と対応づけ。操作を選ぶと、その後に起きたことを「+N 年」つきで並べ、クリックで場所へ移動。
- **変化マップ**（レイヤー）: 直近の操作の直前（または「今を基準にする」）からの標高・植生・領有の変化を橙色で表示（4 枚目テクスチャの A）。感度は `runtime.observe.diffScale`。

## 自動確認（`tests/m5.test.ts`、10 件）
全指標が observables.json に定義あり / 記録間隔・系列長・上限 / 時系列の決定論と Undo / 同条件の比較は差ゼロ・地形が違えば差と示唆 / 降水倍率だけ変えると降水が変わる / 比較は動いている世界を変えない / 変化マップは基準と同じなら 0・変更箇所にだけ立つ / Worker の操作後に変化マップが出る / opId と causeId の対応。
`tests/m1〜m5` はすべて、自作の vitest 互換シム（Node）で通過。実際の vitest・`npm run build`・ブラウザ表示は未実行。

## 見送ったもの（理由つき）
1. **時間スライダ・定期スナップショットによる巻き戻し**（`rewind`）: Undo は Op 単位のリングのみ。任意の tick に戻すには、定期スナップショットからの Op 再生が要る。決定論の土台はあるが、リング・Redo との整合を取る設計が要るため見送り。
2. **侵食レイヤー**: 侵食量のシミュレーション自体が未実装（水文は流量・湖・洪水リスクまで）。レイヤーは無効のまま。
3. 比較は Worker を数秒占有する（その間、動いている世界は進まない）。長さは `compareTicks` で調整。
4. 比較の国指標は国の平均または合計（国どうしの対応は取らない。地形が違えば国の位置も違うため）。
5. 観測量のうち observables.json にあっても未計算のもの（土壌・侵食・疫病・正統性など）は、対応するシミュレーションが無いので記録しない。
