# M4 受け入れ手順（国家・経済・貿易・外交・戦争）

## 実装範囲
- **国家モード**（§21）: 首都 4 つ（最小距離 24 セル）、地形コストの多始点 Dijkstra で領土、初期ポテンシャルの差が tolerance（15%）に入るまで首都を選び直す（ランダム 120 回 → 最小国の首都を動かす山登り 120 回）。国は `nations.setup` の名前・色、AI は seed で性格（拡張主義・自然保護・商業重視・慎重）を割り当てる。プレイヤーは国 1。
- **経済**（§22.2〜22.6）: 食料（人・年）・木材・鉱石・富。貯蔵損失 10%、飢饉（不足 × 死亡率）、技術、**発展度 DI**（8 項目、固定基準、森林率が下限を下回ると上限 70）。
- **貿易**（重力モデル）: 協定のある国どうし、`tradeInterval` ごと。配分 ∝ E_i·E_j / d^θ、価格 = 基準 × (需要/供給)^0.5（上下限つき）、陸 1.0・川下り 0.15・川上り 0.5・海 0.1 + 港の固定費。**Σ輸出 = Σ輸入 + 輸送損失**。
- **外交**: 信頼値（貿易で増、国境の摩擦と上流の取水で減）、状態（平和・緊張・戦争・休戦）、貿易協定・不可侵条約・贈り物・提案と返答。
- **国家 AI**: Utility AI、1 tick に 1 国。緊張が `warWarningTicks` 続いてから、期待利得 − コストで宣戦（前触れなしの宣戦なし）。戦争理由（水・食料・国境）を記録。地形（相手の国境の防御倍率）を見て判断。「戦争中の国へは宣戦しない・自分が戦争中は宣戦しない」（袋叩きの防止）。
- **戦争**（§22.7）: 国境セルの押し引き。損耗は Lanchester の 2 乗則（防御側の殺傷が 3 倍）、地形倍率（平野 1・丘 1.3・森 1.4・山 2.2・湿原 1.5・市街 2.5、川越え 0.4、雨 0.7）、補給（首都からの距離）、装備（鉱石）、戦争疲れ、占領（比 ≥ 1.2 のセルを 1 tick 上限つきで）、首都陥落・期間満了（40）・疲弊・兵力枯渇で終結、賠償、休戦 12。**国は滅ぼさない**（領土は初期の 40% 以上、最後の集落は奪わない）。平和モード（戦争が起きない）。
- **UI**: 国の順位表と DI の内訳・推移、外交パネル（信頼・提案・宣戦・講和）、戦争パネル（前線の地形による説明、動員スライダ）、貿易パネル、レイヤー「領土」「防御地形」、国境線・前線、戦争の矢印、国家モード切替、平和モード。
- Op: `diplo`（proposeTrade / proposeNonAggression / gift / declareWar / proposePeace / cancelPact / respond）、`military`、param `peaceMode`。Undo/Redo は国・外交・戦争ごと戻る。できない操作は `notice` で返し、シミュレーションは止まらない。

## 計画書との差分・出発点の値（要確認）
1. ポテンシャルは居住適性の合計に、農地にできるセルの重み（`farmWeight` 0.7）を加えた。居住適性だけだと「適地に見えて作物が育たない」国が極端に不利になるため。
2. 集落の発生は国ごとに順番（運で国の成長が決まらない）。
3. 食料の収穫は `min(農地の産出, 人口 × 1.25)`（必要な分だけ耕す）。木材・鉱石の産出、富、貿易の輸送単価、戦争の殺傷率などは**計画書に値がない出発点**。`data/*.json` の `_doc` に明記。
4. 「山」は標高の絶対値でなく**陸の標高の分位**で決める（地形の尺度に依存しないため）。
5. 水の不満は「上流から下流への川の流量の長期平均が 20% 以上落ちた」ことで検出（取水の代理指標。植生や地形の変化でも起きる）。
6. 未実装（M5 以降または見送り）: 自然ディレクター・予報、季節、水協定・破壊工作・要塞化・焦土、同盟、輸送容量の上限、川・海の輸送は条件が揃ったときだけ（既定の seed では陸路が大半）。
7. 兵の損耗は人口から引く。国ごとの発展の差は地形の肥沃度に由来するため、弱い国は強い国に押されやすい（袋叩き防止と領土の下限で緩和）。
