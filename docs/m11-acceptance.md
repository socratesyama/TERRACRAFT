# M11 受け入れ記録（等高線を描いて始める）

作品名の由来である「等高線 → 地形」の体験（計画書 §13.3、§21.1「地形は開始前に自分で描く / seed 生成の両方」）が、UI から使えなかった（Op は「ゲーム中は未対応」で、プリセットしか選べなかった）。これを入れた。

## 実装
- 整形（`src/core/geometry.ts`）: Douglas–Peucker で間引き → Chaikin で滑らかに → 始点の近くで終えたら閉じる。許容値・太さ・閉じる距離はすべて `runtime.json ui.contour`。
- 世界の生成: `buildWorld(..., {contours})` が、プリセットの代わりに描いた等高線を使う（風向などはシナリオのまま）。外周に海の枠（標高 `seaBorder`）を自動で足す。これが無いと、最も近い線の標高が外側いっぱいに広がり、海岸を描いても外が陸になった（テストで発見）。
- 描いた線は `contour` Op（tick 0）として Op ログに残り、**共有 URL にそのまま入る**（符号化は既存）。URL から開くと同じ世界になる（hash 一致をテスト）。
- UI: 入口（初回画面と地形パネル）→ 描画モード。線の高さ（海・湖／海岸／低地／丘／山／高山、m 付き）を選んでなぞる。1 本描くたびに世界を作り直して地形を見せる。1 本戻す、「この地形で始める」。最初の 1 本までは案内文（§13.4）。描画中のプレビューは線を重ねて表示。
- タッチ: 1 本指で描き、2 本指でカメラ（M9）。

## 設計判断・食い違い
- 描いた世界は「1 本描くたびに作り直す」方式。プレビュー専用の軽い経路は作っていない（128² で約 100 ms、192² は未計測）。
- 白紙のまま共有はできない（線が 0 本のときはプリセットとして扱われる）。「この地形で始める」は 1 本以上で有効。
- ゲーム開始後の地形編集（山・掘削）は従来どおり残している（§21.1 の「開始後は直接編集できない」とは食い違うが、ゲームとして面白い方を残した）。
